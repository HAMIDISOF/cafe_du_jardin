# Pour_Sol — dépôt de fichiers à lire

Ce dossier est **public** : tout ce qui y est déposé peut être lu par n'importe qui sur Internet, et reste dans l'historique même après suppression.

**À ne jamais y mettre :** clés, mots de passe, jetons ; données personnelles ou d'élèves ; documents sous droits d'un tiers ; tout ce qui est confidentiel.

**Pour lire un fichier** (par exemple `exemple.md`), l'adresse directe est :
`https://raw.githubusercontent.com/HAMIDISOF/cafe_du_jardin/main/Pour_Sol/exemple.md`
